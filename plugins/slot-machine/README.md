# 耄耋机 🎰
（会封号，不敢用了）
TRSS-Yunzai 插件，一个以耄耋为主题的虚拟币小游戏合集。

> **2026-10-28 从独立仓库 `maodie-slot-machine` 并入本库。**
> 老虎机 / 对战 / 借贷 / 管理员命令已在 2026-09-28 因封号风险**注释停用**，
> 当前实际生效的只有「⛏️ 挖矿」和「🏔️ 大冒险」两节，其余玩法文档保留作存档。

## 功能

### 🎰 老虎机
- `#耄耋机` — 免费转（每日3次，固定5000币）
- `#耄耋机 10000` — 下注10000币
- `#耄耋机余额` — 查看个人余额和状态

**符号赔率：**
- 🍒🍋🍊 三同=5倍 | 🔔⭐ 三同=10倍
- 💎 三同=20倍 | 7️⃣ 三同=77倍（JACKPOT）
- 💣 1个=1x扣 | 2个=1.5x扣 | 3个=2x扣
- 🐱 三只耄耋=代币归零+清债

**连胜倍率：** 2连×1.2 | 3连×1.5 | 5连×2

### ⛏️ 挖矿
- `#耄耋机挖矿` — 免费挖矿，30秒冷却
- 💎 宝石=5万 | 🔥 火焰石=2万 | 💠 碎钻=1.5万 | ⭐ 星尘=1万
- 🪨 煤炭=5千 | 🪙 金币=3千 | 🪹 空 | 🐱 耄耋=+100万清债

### ⚔️ 对战
- `#耄耋机对战 @某人 <金额>` — 发起对战
- `#耄耋机接受` / `#耄耋机拒绝` — 接受/拒绝对战
- 双方各押注，随机数比大小，赢家通吃！2分钟过期

### 🏔️ 大冒险（Roguelike爬塔）

入场1万币，3层循环爬塔，死亡归零！

**流程：**
1. **事件层** — 3选1随机事件（18种事件，带趣味描述）
2. **商店层** — 购买道具（18种道具，每轮最多买3个，不可重复购买）
3. **Boss战** — 骰子分配策略战斗（d20骰子，分配攻防）

**命令：**
- `#耄耋机冒险` — 开始冒险
- `#选1` / `#选2` / `#选3` — 选择事件
- `#买 1 5 7` — 购买道具（可批量）
- `#跳过` — 跳过商店
- `#攻7防3` — Boss战骰子分配（7颗攻击+3颗防御）
- `#全攻` / `#全防` — 快捷分配
- `#继续冒险` — Boss胜利后进入下一轮（+1骰子+随机诅咒）
- `#撤离` — 带走所有奖励
- `#冒险状态` — 查看当前状态
- `#冒险撤退` — 放弃冒险
- `#冒险排行` — 冒险历史排行

**Boss系统：**
- 10个Boss，每个有专属效果
- 每轮Boss血量+80，攻击+15
- Boss出招：劈砍/重击/蓄力/连击/吸血/毒雾/毁灭一击（5%概率）
- 第1回合显示Boss行动，每回合结束后显示下回合行动

**Boss专属效果：**
| Boss | 效果 |
|---|---|
| 远古耄耋 | 每回合回复10HP |
| 暴怒耄耋 | 每回合攻击+5（持续叠加） |
| 暗影耄耋 | 每3回合闪避一次攻击 |
| 狂暴耄耋 | 血量低于50%时攻击翻倍 |
| ???耄耋 | 每回合随机触发其他Boss效果 |
| 堕落耄耋 | 每回合吸走玩家5%当前血量 |
| 冰霜耄耋 | 每2回合冻结玩家1颗骰子 |
| 烈焰耄耋 | 攻击附带灼烧，下回合额外扣10血 |
| 雷霆耄耋 | 30%概率雷击，无视防御扣25血 |
| 虚空耄耋 | 每回合永久禁用玩家1个道具效果 |

**诅咒系统：**
每轮Boss胜利后随机获得1个诅咒，永久叠加。

- 轮2（轻度）：嗜血/虚弱/感知下降/嘲讽/脆弱/迷雾/贪婪
- 轮3（中度）：压力/迟钝/嘲弄/淬毒/裂甲/吞噬
- 轮4（重度）：契约/反噬/削骨

**道具系统（18种，全部即时生效）：**

生命类：
- 血瓶（5000）+30血 | 大血瓶（12000）+60血 | 生命之心（20000）+20血上限+20血 | 重生十字（25000）死亡复活

攻击类：
- 攻击药水（8000）+3攻 | 战斗精通（15000）+5攻 | 暴击项链（18000）暴击率+10%

骰子类：
- 骰子袋（12000）+1颗 | 幸运骰子（16000）点数+1

防御类：
- 护盾（10000）挡一次攻击 | 铁壁（15000）减伤+5 | 反甲（20000）反弹10伤害 | 生命汲取（18000）攻击回复10%血量

趣味道具（带负面效果）：
- 耄耋之眼（25000）看到全部出招表，Boss攻击+5
- 幸运草（10000）暴击×3，暴击率-10%
- 赌徒之心（15000）骰子上限30，下限不限
- 耄耋祝福（30000）骰子+5点，最大血量-20
- 偷窃手套（20000）Boss奖励+50%，Boss血量+30%

### 💳 借贷
- `#耄耋机借 10000` — 借10000币（无利息，单次最多100万）
- `#耄耋机还 5000` — 还款5000币
- `#耄耋机欠款` — 查看个人欠款
- `#耄耋机欠款榜` — 谁欠最多

### 📊 排行榜
- `#耄耋机排行` — 持币/欠款/连胜排行
- `#耄耋机功能` — 查看功能说明（转发消息）

### 👑 管理员
- `#耄耋机清空 <QQ号>` — 清空用户数据
- `#耄耋机还清 <QQ号>` — 清除用户欠款
- `#耄耋机驱逐 <QQ号>` — 驱逐用户10分钟无法下注
- `#耄耋机解驱 <QQ号>` — 解除用户驱逐
