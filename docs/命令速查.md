# 命令速查

所有命令默认带 `#` 前缀。带「管理员」的需要 bot 管理员（`#权限` 可查）。

---

## 帮助 / 群管

| 命令 | 说明 |
|---|---|
| `#help` | 功能菜单，发两张图（基础功能 + FF14） |
| `#总结` | 总结群聊最近 100 条 |
| `#总结 200` | 指定条数（上限 200） |
| `#清理闲置会话` | 手动结束闲置超 2 小时的 AI 会话 |
| `#设置名片 名字` | 设置机器人在本群的名片 |
| `@机器人` | 单独 @（无文字、无引用）→ 弹打招呼 |
| `#复读` | 复读你说的内容，然后撤回 |

---

## 群通知（群主 / 群管）

| 命令 | 说明 |
|---|---|
| `#欢迎新人 开启` / `关闭` | 入群欢迎 |
| `#退群通知 开启` / `关闭` | 退群提示 |
| `#通知设置` | 查看本群当前开关状态 |

默认关闭，按群独立保存。

## 语音放歌

曲库默认 `D:/QQBot/music`，哈基米曲库 `D:/QQBot/music-hajimi`。

| 命令 | 说明 |
|---|---|
| `#放首歌` | 随机一首，截高潮 60 秒（同义 `#听首歌` `#放音乐`） |
| `#放首歌 45` | 截 45 秒 |
| `#放整首` / `#放整首 歌名` | 完整播放，按 60 秒拆成多条依次发 |
| `#音乐 歌名` | 自动定位高潮，截 60 秒 |
| `#音乐 歌名 45` | 从高潮起点截 45 秒 |
| `#音乐 歌名 60-95` | 手动指定起止秒数 |
| `#音乐列表` | 列出曲库全部歌曲 |
| `#音乐信息 歌名` | 时长 / 高潮区间 / 是否手工标注 |
| `#音乐扫描` | 重新扫描曲库（管理员） |
| `#音乐标注 歌名 60-95` | 记住这首歌的高潮区间（管理员） |
| `#音乐清除标注 歌名` | 删掉标注（管理员） |

### 哈基米曲库

| 命令 | 说明 |
|---|---|
| `#放首哈基米歌` | 随机一首截 60 秒（同义 `#放哈基米歌` `#听哈基米歌` `#哈基米歌`） |
| `#放首哈基米歌 45` | 截 45 秒 |
| `#放首完整哈基米歌` | 完整播放，按 60 秒拆段（同义 `#放完整哈基米歌` `#听首完整哈基米歌` `#完整哈基米歌`） |
| `#放首完整哈基米歌 歌名` | 指定某首完整播放 |
| `#哈基米列表` | 哈基米曲库清单（转发形式，一条消息） |
| `#哈基米扫描` | 重新扫描哈基米曲库（管理员） |

两个曲库各自独立的洗牌袋，互不影响。

## 耄耋机

纯虚拟币娱乐。老虎机 / 对战 / 欠款玩法已于 2026-09-28 注释停用。

| 命令 | 说明 |
|---|---|
| `#耄耋机挖矿` | 挖矿（30 秒冷却） |
| `#耄耋机冒险` / `#冒险开始` | 开始冒险 |
| `#冒险继续` / `#冒险下一步` | 进入下一层 |
| `#冒险状态` | 看当前进度 / 血量 / 装备 |
| `#冒险排行` | 冒险层数排行 |
| `#冒险撤退` | 中途撤离 |
| `攻N防N` | 与 Boss 对拼（全角 `＃` 也可） |
| `#全攻` / `#全防` | 一次性押上全部攻击 / 防御 |
| `#选1` `#选2` `#选3` | 遇到事件时做选择 |
| `#买 N` | 在商店买东西 |
| `#跳过` | 跳过商店 |
| `#继续冒险` | 连续推进，遇到事件才停 |
| `#撤离` | 结束连续推进 |
